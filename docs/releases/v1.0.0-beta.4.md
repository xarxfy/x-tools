> **X-TOOLS is entirely “vibe coded”** (written with an AI assistant) and has had no independent security audit.
> This is a **beta** – install it on a **separate test VM or LXC (not on the Proxmox host)**, keep backups.

**Install** (as root, on a Debian/Ubuntu VM or LXC with internet access):

```sh
curl -fsSL https://raw.githubusercontent.com/xarxfy/x-tools/main/install.sh | sudo XT_REF=v1.0.0-beta.4 bash
```

**Update from an earlier beta:** `sudo x-tools-ctl update`. Renew the install command of a server to get its IP addresses in the new network overview.
**Remove:** `curl -fsSL https://raw.githubusercontent.com/xarxfy/x-tools/main/uninstall.sh | sudo bash`

### What is new
- **Global search** (`Ctrl/Cmd+K` or `/`): servers, containers, guests, services, domains, customers, jobs, IPs, tags – and the words in your notes.
- **Notes** on servers and services.
- **Group actions**: one action on many servers (updates, SSH keys, firewall rule, restart a service) with a result per server, and an **SSH key overview** that removes an old key everywhere.
- **Inventory** (all servers in a sortable table, hint for systems out of support, CSV export) and **Network** (all IP addresses incl. your own entries, duplicate address warning, CSV export).
- **X-TOOLS as an app on your phone**: *Add to Home Screen* on iPhone/iPad, *Install app* on Android; phone layout with a sticky header, bottom-sheet dialogs and scrollable tabs.
- **Security**: a test checks every API route for missing permissions; a leak of the job heartbeat address by role name is fixed; unknown heartbeat addresses are throttled; React Router updated.

Full list: [CHANGELOG](https://github.com/xarxfy/x-tools/blob/main/CHANGELOG.md). Try the server administration (updates, users, firewall, group actions) on unimportant test servers first.
