> **X-TOOLS is entirely “vibe coded”** (written with an AI assistant) and has had no independent security audit.
> This is a **beta** – install it on a **separate test VM or LXC (not on the Proxmox host)**, keep backups.

**Install** (as root, on a Debian/Ubuntu VM or LXC with internet access):

```sh
curl -fsSL https://raw.githubusercontent.com/xarxfy/x-tools/main/install.sh | sudo XT_REF=v1.0.0-beta.2 bash
```

**Update from beta.1:** `sudo x-tools-ctl update`, then create a new install command for your agents (agent version 7).
**Remove:** `curl -fsSL https://raw.githubusercontent.com/xarxfy/x-tools/main/uninstall.sh | sudo bash`
**Docs:** [Wiki](https://github.com/xarxfy/x-tools/wiki) · **Beta checklist:** [interactive](https://raw.githubusercontent.com/xarxfy/x-tools/main/docs/beta-checklist.html) / [markdown](https://github.com/xarxfy/x-tools/blob/main/docs/beta-testing.md)
**Feedback:** [open an issue](https://github.com/xarxfy/x-tools/issues/new?template=beta-test.md)

### Added
- **Server administration** for Linux servers (admins, agent with *Allow control*, agent version 7):
  - **Install updates** with a live log (apt or dnf; no `dist-upgrade`, no automatic reboot).
  - **Users and SSH keys**: list, add/remove keys, give/take sudo, lock/unlock, create/delete users – the last
    administrator can never be locked out.
  - **Firewall (ufw)**: status, rules, add/delete, on/off – SSH is protected from being blocked.
- **Customer categories** with free names and order (A-customer, B-customer, …): badge, filter, sorted list.

### Changed
- **Overview** redesigned: status banner, two columns, servers with load/RAM/disk, jobs, backup and websites at a glance.
- **Servers page**: one tab per server, collapsible sections, search box on its own row.

### Fixed
- The agent did not start with the new modules missing from its bundle.
